How Gauss elimination works

  1. Write the system as an augmented matrix.
  2. Choose a pivot in each column and swap rows if necessary.
  3. Use row operations to make entries below each pivot zero.
  4. Use back-substitution to calculate the variables.

Allowed row operations: swap two rows, multiply a row by a nonzero number, or add a multiple of one row to another row.
